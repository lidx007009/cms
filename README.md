## AI 报告生成 + 报告内灵活追问 · 落地方案

完整的、可落地的设计方案见 **[`AI报告生成与追问_落地方案.md`](./AI报告生成与追问_落地方案.md)**。

该方案覆盖两个场景：
1. **生成 AI 报告**（基于固定模板）：语义映射契约、业务推理 Prompt、版本快照与血缘。
2. **报告内追问（无尽探索）**：受控技能库(Skills)、面向 AI 的元数据字典、会话焦点状态、动态图表渲染协议。

配套可直接复制的示例文件在 [`examples/`](./examples/) 目录：模板、映射契约、指标库、Prompt、版本快照、技能库(含 Java 实现)、元数据字典、会话状态、图表协议、多轮追问 trace、端到端流水线伪代码。
